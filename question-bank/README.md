# 精准训练题库（第一阶段）

本模块是 \`zmdyy/xqksh-zxxq\` 的独立教师工作页面：\`/question-bank/index.html\`。

## 定位和边界

- 教师用来 **审核/检索训练题 → 加入试题篮 → 预览A4 → 一份Word正面训练、背面答案 → 确认实际布置 → 汇总纸面反馈**。
- 知识星球已有的 **84道迷思诊断题原地独立保留**，不并入训练题库。
- 不依赖大模型、付费 API、TikZ、服务端数据库。
- 题目、原图、答案以及班级布置历史使用浏览器 **IndexedDB** 存储；网页不会自动上传这些私有内容到 GitHub。
- **公开仓库不包含来自第三方平台的题库材料**。源 Word 及其图片请勿直接提交到公开仓库。

## 入口

- 学情分析首页 →「精准练习题库 · 选题组卷」
- 知识星球 → 点选知识节点 →「此知识点的精准训练题库」
- 直接打开 \`question-bank/index.html?concept_id=elec_ohm_law\` 可带统一知识点 ID 进入筛选。

## 首次使用

1. 从聊天下载用户私有的 \`物理精准题库_261题_私人初始导入包.zip\`，**不要上传到公开 GitHub**。
2. 打开题库页面，点击「导入 Word / 题目目录 / JSON」，选择私有 ZIP；浏览器仅在本机解压。
3. 目录中所有261条均默认为「待审核」。打开某题「审核/拆题」，检查题干、关键数值、公式、原图、答案。
4. 多知识点是否需要联合运用，由教师指定「真正交叉应用 / 并列小问 / 选项辨析」；仅有标签不自动定为交叉。
5. 有明确独立小问时选择「识别独立小问」，为 **每个子题单独勾选正确的题图与答案图**，编辑本小问答案后保存。
6. 选择1—3题加入试题篮，设置「自动/单栏/双栏」和答案位置，先点「预览A4正反面」；确认无溢出后导出Word。主页面的导出按钮会自动生成预览并导出；若浏览器阻止自动下载，可以点击“保存已生成的 Word”。
7. 实际印发或布置后才点「确认实际布置」，填班级日期。预览、加入试题篮或重复导出不计入已使用。
8. 收回纸面反馈后可在使用历史点击「录入反馈」，记录人数、常见卡点和训练针对性。
9. 定期点击「备份题库与记录」，保存私人JSON到本地安全位置。

## 导入支持

- \`.docx\` 原题：JSZip在浏览器解析 Word 正文、常见编号、嵌入的PNG/JPEG图片以及独立答案段落。
- \`.doc\`：**仅适用于二一教育组卷目录等HTML表格伪装的 .doc**；传统老式二进制 .doc 需另存为 .docx。
- \`.json\`：题目数组或本模块导出的 \`physics-training-bank-v1\` 备份。
- \`.zip\`：包含 \`bank.json\` 与私有图片媒体目录的离线题库包。

### 重要质量限制

- Office Math/OMML 公式目前只作文本提取，**不会保证保留可编辑分式、上下标和复杂排版**。含公式题目必须逐题审核，必要时手动修改或保留原图。不能把“显示了符号”当成完整保真。
- 多小问共享材料或图片时**不应按编号盲拆**；独立子题必须有完整条件。拆分后的原图、答案图需要逐一勾选，未经确认禁止组卷。
- 作图题答案图不能用任意原图代替；原始 Word 的答案图可能只有图片、没有可提取的文字解析。
- 低分辨率图片会在预览时警告。图形重绘只由教师手动触发，SVG编辑器当前支持直线、箭头、矩形、椭圆与文字；原图原样保存，重绘须核查物理结构。
- 网页预览与 MS Word 使用不同的排版引擎，**第一次打印要核对分页**；超出A4的浏览器预览会阻止导出。
- 本地 IndexedDB 不跨设备同步；清理浏览器数据可能清除题库和使用历史，因此必须备份。
- 初期的纸质练习效果来自教师汇总录入，而非自动收集学生答案；学生勾选的主观针对性不等同于已经掌握。

## 代码结构

- \`index.html\`：独立页面和交互控件
- \`app.js\`：导入、知识点过滤、审核、子题、教师试题篮、Word、历史、SVG重绘
- \`style.css\`：网页交互与A4纸张预览样式
- \`../jszip.min.js\`：既有的浏览器ZIP依赖
- \`../html-docx.js\`：既有的HTML→Word浏览器依赖
- \`../data/knowledge/exam-annotation-catalog.json\`：复用知识星球 \`concept_id\`
- \`../tests/question-bank.test.cjs\`：纯逻辑回归测试

\`npm test\` 已包含题库测试。需要浏览器端的回归检查：至少选择一份真实Word，验证导入题干、图片、答案匹配，检查单双栏预览，再用 Word 打开试印。

## 后续可扩展但未宣称完成的部分

- 新增 \`tests/question-bank-student-export.test.cjs\`，校验首字母、完整拼音、跨班同名、子题级导出记录及通用模式。

> 浏览器开始下载并不意味着文件必然被保存或学生拿到了纸张，因此状态以「已生成/发起下载」为准；教师仍可在单独的「确认实际布置」中记布置历史。

## 题库质量审核中心（正式功能）

question-bank/index.html 顶部只保留「题库质量审核」入口。原来的题型复核和图片修复顶部入口已合并；待办动态从本地题库生成，不固定为346道。

- 待办总览：整合每题各项审核状态和机器初筛风险。风险提示不是错误结论。
- 图片：原图、答案图、修复候选和备用高清PNG核对，支持直接采用或保留；高级批量图像对照可导出私人完整ZIP。
- 公式与单位：题干和答案文本可修订，重点核验上下标、分式、计算步骤及单位。
- 答案：核验答案、解析和配图；答案完全缺失时禁止将该维度直接标为通过。
- 重复题：规范化题干初筛，人工检查对应原图与数值；不自动删除。
- 知识点：编辑知识点标签及关系，并在该维度保存时才刷新概念ID。
- 题型：保留原346题及教师审核结果，主类型和次级考法并行记录。

### 数据格式及保留约束

每题用 qualityReviewV1.<dimension> 记录 status、note、signature、reviewedAt，支持 pending / approved / repair / discuss。若通过后相关内容修改，签名不再一致，动态展示 stale（需要重新核验）。
这是质量维度审核，不会直接更改原题 review（整题正确性审核）。已存在的 typeAudit20261011.teacherReview、images[].repair 和题目ID保持有效。
所有数据仍保存在浏览器的 PhysicsTrainingBankV1 / questions。导入题库ZIP时保留本地人工结果；导出质量审核记录JSON只导出审核元数据，不包含题图。需要全量迁移时使用原页面的“备份题库与记录”。

### 验收重点

刷新后进度不丢；修复后本题仍可完成确认；修订已确认答案后提示重新核对；原图不自动覆盖；不同配图的同文本题不自动删除；修订公式时不重算知识点ID；原有检索、组卷及Word导出应保持可用。

### 审核工作区布局（2026-10-11优化）

质量审核不再常驻“题号队列＋原题＋编辑”三栏。题号队列默认收进左侧抽屉，顶部“☰ 题目列表”可随时展开选择题目，选中后自动收起；底部可直接上一题／下一题。中间仅保留原题与操作两栏，默认原题45%、编辑55%，可切换“扩大编辑区”达到30%／70%。窄屏自动改上下布局。编辑区正文滚动与原题阅读相互独立，保存、通过、修复、待讨论操作固定可见，避免长题干或长公式将操作推到不可见区域。题目计数改为当前第 N / 总数。

## 质量审核交付闭环 V2（2026-10-11）

教师端仅有三种确认动作：**需修复、排除疑点、保存修改**；主类型放在同一操作栏的下拉框。所有项目状态按风险诊断、每条疑点的教师判定、修改记录、版本更新结果自动计算，不应把纯规则筛查通过误称为“物理正确性已审核”。

异常数据来自 quality-diagnostics.js：每条标注异常位置、类别、触发证据、可追溯片段和精确性。可准确定位的文本片段在题干或答案中高亮；不能定位时明确“仅规则怀疑，尚未定位”。知识图谱名称未匹配是技术标签问题，不视作物理内容错误。

答案和答案图始终显示，毋需展开。重复题使用双题对照（题目A/B），同时展示题干、全部题图和答案，并允许选择完全重复／变式／不同题，绝不自动删除。

一题可有多个独立疑点；每项基于稳定疑点ID保存教师结论，排除某一条不意味着同维度其他疑点也已排除。已修改状态为“已修改待复核”；批量更新替换了相关内容后状态为“修复待验收”；只有所有规则检出的疑点均被解决，才能显示“规则检查通过”，且与整题物理正确性认证明确区分。

点击顶部“导出修改清单 Excel”，在本浏览器生成一个轻量 XLSX：待修复／教师修改／已排除三张表，无整题图片；包含题目ID、题库版本、字段修改前后、疑点位置、类型和规则依据。quality-export.js 用现有 JSZip 生成 OpenXML 工作簿，无额外API；已导出事件ID写入 settings.qualityExportLedgerV2，重复点击仅导出新增记录。此表可直接在聊天中交付，用于服务端按母版修订题库。

顶部“更新题库版本”可选择新版完整ZIP；默认原“＋导入题目”的ZIP路径也走此自动流程。bank-version-update.js 会先验证 bank.json 格式、全部题目ID及接受的图片资源，依据稳定ID和修订版本选择安全更新项；通过 IndexedDB 单个 readwrite 事务同时提交新增、修订和设置。失败则浏览器事务自动回滚，不会发生半更新。原题使用记录和教师确认结论继续保留；修订后的受影响项重新等待验收。冲突自动跳过、记录ID并提示数量，不要求逐条人工合并。原题变化的紧凑差异备份存于 settings.bankRollbackV2。

说明：原有 bank.json 的 version=1 属于数据格式版本，不能用于新旧批次判断。现在优先识别 bankVersion/buildId，缺失时以导入文件名及数据摘要区分批次，拒绝可识别的降级；不能通过日期比较的包不会被默认为更旧。

验收重点：旧1414题版导入新版1460题修订包时，新增ID不重复；已完成的教师备注不消失；因修复变动的审核项目不会自动被判通过；常规错误公式可定位并高亮，不能定位的提示不虚构位置；一题多个异常需要分别处理；XLSX不含题图；导入失败原数据库应保持一致。

## 2026-10-13 · 审核整页化、选项图、双栏续排、一键采用

- **质量审核改为整页视图**：点「题库质量审核」后，审核界面铺满窗口，题库主页暂时隐藏，只剩一个滚动区域；地址变为 `question-bank/index.html#review`，可直接打开、刷新后保持，浏览器后退或「← 返回题库」回到主页。
- **物理编辑器入口固定在工具栏**：「打开物理编辑器 · 单位 / 公式 / 对照」与「题目列表」「扩大编辑区」并列，不再放在审核区内，避免被“点击定位”的滚动顶出视野，也不再挤掉底部操作栏。
- **编辑器可以滚动**：全局 `main{margin:auto}` 曾让编辑器右侧 `<main class="te-main">` 不受弹窗高度约束而无法滚动，现在编辑区单独 `margin:0`。
- **一键采用书写建议**：编辑器疑点栏新增「采用全部同类（N 处）」和「采用本题全部（N 处）」。批量结果只写入草稿，一次「撤销」整体恢复；规则可能把型号等误判为下标，正式保存前请用「查看修改」核对。只在单题内批量，不跨题修改。
- **选项图**：题图对象可带 `option` 字段（如 `"A"`），表示属于哪个选项。
  - 新导入的 Word 按图片在段落中的位置自动记录：图片前最近的选项字母即其所属选项。
  - 已有题目：若选项文字为空（如单独的 `A．` 行），且图片数等于选项数（或多 1 张题干图），质量审核「图片」页提示「选项图未配位」，可「采用配图建议」一键按顺序配给 A/B/C/D；物理编辑器里每张题图也可手动选择「所属位置」。
  - 审核页、A4 预览和 Word 中，仅有字母的图选项按 2 列网格并排；未标选项的题图放在选项之前。共用逻辑在 `option-images.js`。
- **A4 双栏自然续排**：不再固定“第1/3题左栏、第2/4题右栏”。预览使用浏览器分栏，Word 使用真正的分栏节（`w:cols`），内容先填左栏再接右栏，长题可以在段落间断开；图片、选项网格不拆开。Word 会自动平衡两栏，断点与浏览器预览可能略有差别，第一次打印仍建议核对。预览中也不再重复原题号（如“3. 15．”）。
