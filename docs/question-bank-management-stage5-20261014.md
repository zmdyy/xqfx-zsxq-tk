## 本阶段修复

1. 编辑器更正知识点标签或小问后，若导入记录中的整题主知识点已不在当前关联知识点中，则撤销旧主归属。原值记录在质量修改历史的 `previousPrimaryConceptId`，教师修改保护及其他原题字段保持有效。
2. 审核页更正标签后，旧主知识点下拉选项不再被写入新的知识点集合；仅使用当前集合中的有效选择，已失效的旧选择回到更新后的标注结果。保存时根据评分单元主知识点同步整题主归属；各单元不一致或未确认时保留未确定状态。根字段变化进入既有修改历史。
3. 完整恢复时，先以原始备份记录完成事务写入，再在页面的显示副本上计算派生标注。旧题缺少映射时，不会因恢复操作补充显示用元数据而误报为备份后题目修改。
4. 主页排版提示改为“超出仍可导出 Word”，与实际导出行为一致。
5. 修复旧知识/数学测试遗漏当前打印排版模块的依赖；新增完整流程测试及统一发布验收命令。

## 完整流程验证

`tests/question-bank-full-flow-browser.test.cjs` 在隔离浏览器中执行：

- 导入模拟 Word 试卷；确认预览不写入、正式导入后保留试卷文件名与题号。
- 教师修改题干、答案、题型、知识点并保存，保留教师修改历史。
- 从统一 V2 更新包添加带图片题目，同 ID 的远端答案不能覆盖教师修改。
- 在编辑器和审核页分别更正知识点，验证旧主归属和旧选择不会继续影响统计。
- 打开网页审核、浏览器后退回主页，保持原有页面导航规则。
- 通过实际布置操作记录 801 班练习；保存未提交草稿，确认正式答案未被草稿覆盖。
- 后台生成完整 ZIP；题图和答案中的同一 PNG 只保存一份独立资源，保留使用记录、草稿、教师历史和导入记录。
- 使用第二个完全独立的浏览器配置恢复 ZIP；验证题干答案、原文件名、图片、修改历史和使用记录，以及恢复后题目新增/修改/删除均为 0。
- 验证恢复的草稿、切换题目后的编辑工具和旭日图数量。
- 导出超过 A4 的双栏 DOCX；核对末段文字、正式答案、图片、原生分式、下标与撇号上标、真实双栏，以及“仍已导出”的提示。未保存草稿不混入导出的正式内容。

同一测试支持 `BANK_FLOW_URL` 指向发布页面，供最终线上验收复用；其浏览器配置完全隔离，不读取用户正在使用的浏览器题库。

## 其他回归覆盖

34 份测试包括题库已有功能和同仓库相关基础回归。其中题库覆盖：旧 ZIP/JSON 与 V2 包、缺图/篡改包拒绝、故障事务回滚、多文件导入、教师修改保护、公式及同类 68 处批量建议、独立编辑区滚动、审核网页导航、3500 道题后台备份取消/重试及快照一致性、统计计数守恒和手机布局、Word 段落流动与不可拆块。

3500 道题备份测试中页面心跳持续运行，当前最终回归最大间隔约 34ms；这个数字仅代表验收环境。中文排版检查使用完整的中文字体，避免字体缺失造成错误的行高和分页判断。

## 日常操作

- 新试卷或新题：主页“添加题目”→“从文件导入”或“粘贴单题”→核对摘要→开始导入。Word 自动提取后仍需检查答案、公式和图片。
- 更新包：仍从“添加题目”导入，自动识别用途，保留教师修改并报告冲突。
- 日常备份：“备份与恢复”→“下载完整备份（ZIP）”。生成后在浏览器下载列表确认文件已经保存。
- 换浏览器或恢复数据：“备份与恢复”→“恢复个人备份”→核对同 ID 覆盖范围→确认恢复。当前其他题目仍保留。
- 统计：点击“题库明细”，查看大类及旭日图；“查看本组题目”可回到精确范围。

## 验收边界

这是软件功能和数据往返验收，使用模拟试卷、隔离数据库及压力数据。没有取得用户浏览器中的私有完整题库，不宣称已经逐题审核其物理正确性，也不提供其实际压缩率。现有数据库名称继续沿用；本次没有进行同源数据库迁移，原题库无需重新导入。
