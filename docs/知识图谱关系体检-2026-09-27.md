# 初中物理知识图谱关系合理性体检

日期：2026-09-27

## 体检目标

本次体检不按“教材章节出现顺序”机械连线，而按以下四类关系重新判断：

1. **前置关系 prerequisite**：后一个知识点确实需要前一个知识点才能理解或操作；
2. **因果关系 causal**：前一个概念能解释后一个现象或应用，但不是严格学习前置；
3. **并列关系 parallel**：同一上位概念下的不同分支、类型、情形或对照；
4. **跨模块关系 cross_module**：不同物理模块之间确有明确物理联系。

重点处理“本应一对多 / 多对一，却被错误串成单链”的情况，并清理关键词误连、重复边和悬空边。

## 本轮主要发现

### 1. 教材顺序被误当成知识依赖

典型问题包括：

- 重力 → 弹力 → 摩擦力 → 受力分析
- 音调 → 响度 → 音色
- 串联电路 → 并联电路
- u>2f → f<u<2f → u<f
- 轮船 → 潜水艇 → 气球飞艇
- 杠杆 → 滑轮 → 滑轮组 → 斜面
- 太阳能 → 核能 → 核聚变/裂变 → 可再生/不可再生

这些关系已经改为“共同前置节点 + 分支”或“并列比较”。

### 2. 汇聚型方法节点连接不足

重点修正：

- **受力分析**：由力的示意图、重力、弹力、摩擦力共同汇入；再分流到二力平衡、力与运动状态和同一直线二力合成；“压力”与受力分析保持直接关联，但不再错误设为“受力分析之后才能学习”。
- **欧姆定律**：由电流、电压、电阻共同汇入。
- **密度测量**：由密度、质量测量、长度/体积测量共同支撑。
- **物态变化中的能量转化**：由熔化/凝固、汽化/液化、升华/凝华三类变化共同汇入。
- **凸透镜成像规律**：分叉到三种物距情形，再分别连接照相机、投影仪、放大镜。

### 3. 并列概念被错误串联

已重点改为并列关系的包括：

- 匀速运动 / 变速运动
- 时间测量 / 长度测量
- 音调 / 响度 / 音色
- 重力 / 弹力 / 摩擦力
- 液体压强 / 大气压强
- 轮船 / 潜水艇 / 气球飞艇
- 杠杆 / 滑轮 / 斜面 / 轮轴
- 熔化凝固 / 汽化液化 / 升华凝华
- 凸透镜 / 凹透镜
- 三种凸透镜成像物距情形
- 串联电路 / 并联电路
- 电流表 / 电压表
- 电流磁效应 / 磁场对电流作用
- 太阳能 / 核能

### 4. 清理关键词误连和悬空边

删除或替换了多组明显不成立的关系，例如：

- 阿基米德原理 ↔ 水的比热容
- 摩擦力 ↔ 磁现象
- 凸透镜成像规律 ↔ 欧姆定律
- 透镜 ↔ 电流
- 牛顿第一定律 ↔ 热学能量守恒
- 电流磁效应 ↔ 牛顿第一定律
- 能源分类 ↔ 功
- 液体压强 ↔ 沸点与气压（改为“大气压强 ↔ 沸点与气压”）
- 光的直线传播 ↔ 速度（改为“光速 ↔ 速度”）
- 声音传播 ↔ 光速（改为“声速 ↔ 光速”）

同时删除了指向不存在节点的悬空关系。

## 数据结构原则

现在以 `data/knowledge/知识点数据库.json` 中的 `prerequisites` / `follow_ups` 作为学习路径元数据，
以 `knowledge/关系修正数据库.js` 作为运行时关系校正层。

校正层中的 `auditAdd` 对同一节点对具有最终解释权，避免原始启发式关系覆盖人工校准结果。

## 后续维护要求

```bash

```

若出现重复边、悬空内部边、孤立节点或 prerequisite 元数据不一致，应先修复再发布。


## 视觉结构自动优化

关系体检之后继续检查了空间布局。原页面直接使用知识点数据库中的旧坐标，这些坐标仍带有大量“按教材顺序排成链”的历史痕迹，而且力学、光学、热学、能量等模块中心距离过近。

现加入 `knowledge/layout-engine.js`，运行时按以下层级重新计算布局：

**物理模块 → 章节子簇 → 章节核心节点 → 关联知识点**

随后执行确定性的局部松弛：
- 同模块节点自动排斥，避免重叠；
- 前置、因果、并列关系采用不同目标距离；
- 高连接节点获得更大的安全间距；
- 章节锚点保持模块结构稳定；
- 六个模块使用独立三维空间锚点。

当前自动视觉体检结果：
- 183 个节点均获得有效三维坐标；
- 各模块内部最小节点间距均高于 22；
- 距离最近的两个模块为“力学 / 热学”，最小间距约 82.9；
- 模块内不存在距离小于 22 的节点对。

标签显示也增加了屏幕空间碰撞规避。尤其修复了一个实际显示 bug：旧代码在选中任意节点后，把 `selectedId` 作为全局布尔条件，导致几乎所有标签同时显示。现在聚焦模式只保留当前节点和直接关联节点，并按优先级自动隐藏相互遮挡的普通标签。

对应自动检查：

```bash
node tools/audit-visual-layout.js
```


## 2026-09-29：81 条旧跨学科引用正式清洗

本轮对 81 条旧 `cross_disciplinary` 悬空引用完成正式清洗：**14 条直接保留为跨学科支撑、30 条改为应用关联、16 条修改后保留、18 条删除或替换、3 条降为二级拓展**。

保留的外部关系已经全部创建真实卫星节点，使用 `node_type: satellite` 与 `satellite_kind: cross/application/extension`。它们不会进入学情分析平台只接收 `node_type = core` 的 AI 主知识点词表。

关键替换包括：`micro_electron → elec_charge`、`micro_nucleus → energy_nuclear_fusion_fission`；“电流的磁效应 → 电解”已删除。液压系统改由帕斯卡原理连接，桥梁受力改由受力分析连接，地磁导航改由地磁场连接。

前台总览默认隐藏新卫星；点击物理知识点后展开跨学科卫星与应用卫星；二级拓展需再次点击“展开”后显示。鸟类飞行、重力分布、守恒思想比较均只放在二级拓展。

从本版本起，图谱审计不再豁免跨学科关系：任何关系端点不存在都视为错误。
