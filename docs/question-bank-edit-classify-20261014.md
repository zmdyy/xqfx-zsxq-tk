# 上下标、快速大类归类与识别增强

## 实际操作

- 文字编辑区：例如 `VM`，只选中 `M` 后点“下标”，直接成为可编辑的 `V_M` 公式。数字下标后紧接撇号时，撇号保留为上标。无可识别基符号时打开公式框供补充。
- 公式框：选中要放到上下标位置的字符，或把光标放到基符号之后，点击下标/上标即可看到输入位置。按钮保持公式输入焦点；结构空位未填写不能保存。
- 题库明细：点待归类、其他或任意大类，再点“整理本组分类”。左侧题干、图片和答案可滚动查看；右侧只选大类即可保存，支持保存并下一题。
- “同时细化知识点”默认关闭。启用后可选主知识点、补充关联知识点；只选大类不会要求填写这些信息，不会改写题干、答案、图片及原有标签。
- 自动建议展示依据；“采用大类建议”只选择当前建议，点击保存后才写入。无可靠依据时仍需手选，不强行自动分配。

## 统计与保存

教师指定的大类保存在题目 `physicsCategoryV1` 字段，优先于原标签自动归类。没有与该大类一致的明确主知识点时，进入“大类 → 原题型 → 知识点待细化”。明确主知识点可继续显示具体叶节点，每题仍只计一次。

分类保存读取最新题目并校验完整记录及修订号，在事务中只更新分类/可选知识点信息、修订号和修改历史。教师操作受更新包保护；已有草稿不被删除。完整 V2 ZIP 自动包含分类字段，恢复后有效。数据库没有更名或迁移。

独立明细页的分类按钮跳回题库并打开相同的分类界面。

## 识别增强与边界

- 补充质量符号 `m1、m2`；有数值前缀的 `10 m2` 按单位指数处理，独立 `m2` 提示结合质量/面积语境核对。
- 补充 `VM、VN、Rg` 等字母下标候选，保留型号/乘积的上下文提示。
- 补充连续相乘 `R0I1` 和含多个疑似下标的整式 `U2=R0I1`；普通 `U1=1` 仍按单个数字下标处理，保留既有精确定位与同类批量操作。
- 检查已有数学定界符内部的原始写法；修正结果不嵌套额外数学定界符。文字/单位宏的文字区域不强行按变量处理；已规范的上下标不重复提示。
- `R01` 一类疑似字符误认/遗漏单独标记，要求逐处核对原 Word/图片后确认，不允许同类批量采用。候选不是原件正确性的证明。
- 未发现疑点时明确提示检查范围，继续保留人工核对要求。本轮没有训练新的 OCR 模型或批量重写私人题库。
