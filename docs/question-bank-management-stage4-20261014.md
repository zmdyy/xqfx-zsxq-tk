# 题库管理第四阶段：物理大类统计与旭日图

## 使用方式

主页点击“题库明细”，在知识点覆盖图之前查看新增统计。独立的 `question-bank/dashboard.html` 也显示相同组件。

1. 顶部按声学、光学、热学、力学、电磁学、其他、待归类显示题量。零题的大类仍显示卡片。
2. 旭日图为四层：中心总题数 → 物理大类 → 题型 → 主知识点。
3. 点击扇区或右侧分组按钮逐层展开；悬停查看题量和占当前统计范围的比例。上方路径可回到任意上级，也可“返回总览”。
4. 点击“查看本组题目”返回题目列表，保留精确的大类、题型、主知识点和“仅已审核”范围。主页显示可移除的“旭日图范围”筛选；移除或重置后，刷新不会恢复已取消的范围。
5. 手机总览保留完整环形结构，减少外层文字，避免重叠。点击大类后逐层查看；分组按钮支持触控和键盘操作。

## 统计口径

- 有效大题按稳定 ID 去重，不含 `archivedAsDuplicate` 归档重复题。每题只进入一个叶节点，各层子项之和严格等于父项及中心总题数。
- 目录中的“声现象”章节目前位于力学模块，统计时全部单列为声学，涵盖声音产生、传播、声速、音调、响度、音色、噪声、超声/次声、频率、振幅、振动这 11 个核心知识点。
- 能源、数学和跨学科支撑等已有明确目录归属的知识点列入“其他”；目录无法识别或跨大类主归属未定的题目列入“待归类”。不会通过题干关键词强行分入五大类。
- 优先读取整题明确的 `primary_concept_id`。没有时使用现有知识标注：各评分单元主知识点一致，则整题归入该知识点；多个主知识点属于同一大类，则归入该大类下的“主知识点待确认”；不同大类则进入待归类。
- 旧题的 `concept_ids`、标签、别名及小问标注可作为归类依据。只有唯一明确知识点时才进入具体叶节点；关联多个知识点且未确定主知识点时保留待确认。仅有大类标签的题目也保留待确认叶节点。
- 原有知识点覆盖表继续按“关联”统计，一题可以关联多个知识点；旭日图按“单一主归属”统计。页面明确说明两种口径。

## 数据与兼容

组件只计算视图，不保存类别、主归属或新的题库版本，不改题干、图片和原标签。两处统计和题目列表使用同一分类逻辑。旧记录只有 `concept_ids`、没有文字标签及映射时，主页的初始化会保留这些 ID，避免被语义标注清空而无法统计；这也是内存兼容处理，没有批量改写 IndexedDB。

知识点目录读取失败时显示明确状态，未识别题目继续保留在待归类。无题库时显示空状态，不生成虚构数据。此版本没有执行任何数据库迁移。

- `npm run test:distribution`：目录 257 个知识点全量归类、11 个声学节点、整题主知识点优先、多评分单元同类/跨类、其他/待归类、归档与重复 ID 排除、各层题数守恒、源记录不变。
- 浏览器使用 13 道有效题和 1 道归档题，覆盖两处统计一致、真实画布扇区点击、四层结构、逐层查看、按主归属精确返回题目、已审核范围、移除筛选后刷新、空库、390px 小屏、文本转义、目录请求失败。比较查看前后的原始数据库记录，确认没有统计操作写入。
- `npm test`、`npm run test:management`、`npm run test:editor` 通过，原有导入、备份恢复、编辑器和审核流程回归通过。
