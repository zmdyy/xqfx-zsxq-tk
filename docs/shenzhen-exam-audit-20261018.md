# 深圳五年考情核验与页面更新（2026-10-18）

核验依据：用户上传的深圳2021—2025年Word整理版及原有22张考情汇总图。已逐题建立90组题、161个任务的对应，不将其标为官方原卷已核验。

## 页面变化

- 默认18行五年考点速览，格内题型简写；详细25专题热力表保留。
- 同年同专题多次出现只计1个考查年份；合并专题按任务ID去重。
- 点击年度专题可看任务、题型、认知要求、来源位置与计分依据。
- 查看原题从本机题库按稳定ID或完整来源加题号匹配，兼容合并重复题；保留图、答案和整题加入试题篮。
- 筛选相关练习不限地区年份，可移除题型/知识点标签；返回考情恢复选择。
- 数据只读，不改动浏览器题目、审核或使用记录。

## 统计口径

按显式设问及选择题辨析项标注；背景材料不单独计为考点。2021年覆盖包含两套选做题。
仅累计有明确计分依据且可独立归属的任务；跨专题共享分值、转录疑点与未核小问分值不累计，不提供整卷占比。
未见表示上传整理版未见，区别于确认未考；2020年仅保留旧图片资料。

认知要求是任务标注，不能当作实测难度。小问型任务与整组题的题型可能不同，筛选时允许解除题型限制。

## 已修正的明确项目

- 2021年声学：旧图3分，上传Word明确单选每题2分，改为2分。
- 2024年月壤第6题：配套目录标压强，按正文改为质量与重力辨析。
- 2025年蓄冷剂：将重复列示的整组6分改为小问对应，不重复累加。
- 2023年压强探究：按正文实验任务归为实验题，不沿用旧图填空题标签。
- 2024年液体压强射流实验：按正文归为实验题，保留图线绘制任务，不误归计算题。
- 2025年重力示意图与杠杆实验区分；实验中使用重力知识不等同于单独的重力实验。

## 待核项目

- 2021年20、21题为A/B选做，覆盖包含两套备选任务，不能相加作为卷面分值。
- 2025年整理版使用12个来源组号，不推定其全部原卷题号。
- 原解析把水总放热量与每克蓄冷剂吸热量混写；整组分值不能重复计入各考点。
- 无人机升降耗能3.2×10⁹ J与解析结果不一致，数值计算待核。
- 来源数据表的电流、电压数值及表头疑似错位，保留原表待核。
- 来源第4组杠杆数据不满足平衡关系，须核对原卷或完整设问。
- 背景中的航天器名称及发射信息有误，物理设问单独对应，未改写原文。
- 船底面积题干为10⁻³ m²，解析使用10³ m²，数值矛盾。

分值限制：仅有22个任务有Word正文的明确计分依据，其中11个跨专题共享、11个可独立归属；其他139个任务仍待核。配套目录存在异常总分或错标，未直接采信；旧截图作为可展开对照保留，不宣称小问分值全部核准。
