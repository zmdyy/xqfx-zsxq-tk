# 题库第四阶段：Word 连续双栏与超出提示

范围：`zmdyy/xqfx-zsxq-tk` 的 Word 导出。保留第三阶段的浏览器连续分栏预览，以及前两阶段的编辑器、准确高亮和同类批量修改。

## 已完成

- 使用 Word 原生双栏，题目按顺序从左栏接到右栏，再续到下一页；取消按奇偶题分配两格表格的做法。
- 预览与 Word 共用题干、答案、选项、图片和表格的内容分块。段落之间、不同选项之间可以换栏，整道题不再被捆成不可拆分的块。
- 单个选项的文字与明确归属该选项的图片保持连续；图片等比例嵌入 DOCX。仅有空选项标签与未记录归属的图片时，保留整个选项图组，不猜配选项。
- 普通答题表和反馈表通过不拆行的单格容器保持整体，避免分栏平衡时把短表拆到两栏。这些容器不承担试卷双栏布局，试卷分栏仍由 Word 原生栏设置控制。
- 标题、姓名信息和反馈表通栏显示；参考答案从新页开始。页脚使用实际页码和总页数字段。
- 公式继续生成可编辑的原生 Word 公式，保留数字下标及独立的上标、撇号。
- 单栏、双栏或自动版式超过 A4 正反面时，提示后仍可导出，不新增确认弹窗。提示保留在预览、生成完成信息和主页状态中；手动版式选择保持不变。
- 原有未审核题目的确认、学生导出记录、文件名、下载链接和生成失败提示保留。
- SVG 转 PNG 时保留原始宽高比及显示尺寸，避免分别调整画布宽高造成图片拉伸。

## 验证结果

基础测试 `npm test`、编辑器回归 `npm run test:editor`、连续预览 `npm run test:preview` 和实际 Word 下载 `npm run test:word` 均通过。

通过网页真实下载三份 DOCX，解析全部 XML，并用文档技能的 `render_docx.py` 经 LibreOffice 渲染。最终共 11 页，逐页检查中文字形、内容、配图、表格、公式和页脚；另用 `tests/question-bank-word-render.test.py` 检查实际渲染位置与内容完整性。

| 场景 | 结果 |
| --- | --- |
| 十段长题、带配图选项和四行实验表 | 题目一页、答案一页；长题跨栏，A/B 配图与对应文字在同栏，实验表完整位于同栏 |
| 下标与撇号、分式公式 | 原生公式保留，撇号仍在上标位置；公式未改成图片 |
| 七十五段题干、六十五段答案，手动单栏 | 成功导出六页；逐段核对顺序，无遗漏或重复，超出提示可见 |
| 六十六行的超高答题表 | 成功导出三页，六十五条实验数据全部保留，单行不拆分，超高提示可见 |
| 超出处理 | 预览入口和主页导出逻辑均允许超出；浏览器下载没有新增确认 |
| 历史与失败处理 | 学生生成记录、子题版本快照、取消操作和可见错误回归通过 |

样例是测试构造的数据，未修改用户正式题库。渲染验收使用 LibreOffice；没有在用户电脑上的 Microsoft Word 中执行测试。

## 排版边界

浏览器和 Word 使用同一内容顺序、A4 尺寸及相同分块规则，但字体和排版引擎不同，具体换栏位置和页数可能不同，不承诺像素级一致。

本身就超过一页高度的选项或答题表无法在维持可读字号的同时放入一栏。对于过大的表格，导出保留全部数据并允许在行之间续页，不强行套入不可拆分容器导致裁切；网页提示教师在 Word 中调整。普通可容纳的答题表保持整体，图片和单个表格行不拆。

自动版式仍检查单栏与双栏并选取合适的预览版式；此检查只提供提示，不再构成 Word 下载的前置限制。
