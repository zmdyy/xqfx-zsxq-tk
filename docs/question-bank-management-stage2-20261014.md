# 题库管理第二阶段：集中入口与来源显示

目标仓库：`zmdyy/xqfx-zsxq-tk`。本轮按用户要求先执行第二阶段，沿用现有浏览器数据库和文件格式。

## 已完成

- 顶部只保留题库明细、题库质量审核、添加题目、备份与恢复四个入口；检索栏移除导入按钮，主页不再独立导出大JSON。
- 添加题目提供从文件导入和粘贴单题。选择文件后先识别用途、显示题量估算，点击开始后才执行；完成后显示实际新增、合并、质量修订或冲突保留数量。
- Word保留完整原文件名与原题号；重复题保留多个来源。主页卡片、审核队列突出试卷名称，原始文件名可查看。编辑器可以补充试卷名称，原文件名不被覆盖，名称修改进入草稿及教师修改历史。
- 增加试卷来源、导入范围筛选；关键词检索包含补充名称及所有来源。导入完成及历史记录中可查看新增题目，多文件导入的查看按钮包含本批全部新增题目。
- 原题库ZIP走已有受保护更新流程；个人备份ZIP及旧JSON可选择仅添加题目或恢复完整记录。添加入口默认保留现有个人内容，恢复入口默认展示同ID覆盖范围并确认后恢复。
- 导入与更新记录写入现有settings存储，包含文件名、时间、处理方式、数量和新增ID；既有完整ZIP备份已经导出此存储，因此记录随备份保存并能恢复。上线前缺少的导入日志不会伪造补齐。
- 更新ZIP预读对象复用，避免为摘要和正式更新重复读取同一个包；保持原版本校验、教师修改保护及事务更新逻辑。
- 新建单题前重置筛选，避免保存新题后因旧筛选条件看不到它。

## 验证

- `npm test`：通过。
- `npm run test:management`：真实浏览器验证Word预览不写入、导入、重复合并、多来源检索和筛选、名称修改、审核队列显示、教师修改保护、完整ZIP下载及空题库恢复、旧JSON安全合并、多文件新增范围、无效文件、桌面与手机布局。
- `npm run test:editor`：通过，覆盖草稿、历史、并发保护、新题、ZIP恢复及编辑定位。
- `npm run test:review`：通过，覆盖网页审核及后退/前进、滚动恢复、嵌套编辑器和直达链接。
- `npm run test:preview`、`npm run test:word`：通过，覆盖顺序双栏、不可拆块、超出仍导出和原生Word内容。
- 浏览器验收使用隔离数据库和虚构试题；未操作用户正式题库。桌面1366×768和手机390×844均检查无横向页面溢出，并检查操作面板及Word导入摘要截图。测试环境补齐中文字体后完成排版回归。
