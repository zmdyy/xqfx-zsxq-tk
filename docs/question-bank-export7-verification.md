# 分类与练习导出调整（2026-10-14）

- 主知识点使用统计页同一套物理分类规则，随大类选择过滤；声学按声现象章节识别，不误归力学。已保存手动分类及采用建议时同样更新候选项；不自动替教师选择主知识点。
- 明显的段内连续空白转换为填空横线，用于资源卡、练习预览及原生 Word。排除公式、表格、英文单词间距、选项标签后的排版空格。编辑器以边线显示原空白，保存不改写源文。新导入 Word 中带下划线的空白保留为横线。
- 页面与审核页名称改为“题库”。
- 默认导出【答案】【解答】，组卷设置可分别勾选【知识点】【分析】【解析】。无分栏标题的旧答案原样保留；若仅有未勾选栏目，显示操作提示而非生成不存在的答案。选项改变会使旧下载与预览失效，重新生成时按当前选择；完整题库答案与图片保留。
- Word 与网页预览页眉删除日期填写栏及“少量多次 · 独立完成”，保留班级姓名。标题中的生成日期不受影响。

## 边界

不会推断已经丢失且不含空白字符的填空位置；可在编辑器用下划线补齐。原题答案图片缺少栏目关联信息，继续保留，避免误删解答所需图示；本文本栏目设置不改写题库及备份。
