# 历年考情与选题联动（2026-10-17）

入口：题目明细 → 历年考情。新增内容仅属于题库页，未修改学情分析或知识宇宙。

## 数据与统计

- `question-bank/exam-data.json`：25模块、170条年度记录，依据用户提供的22张图片整理。部分一行多题型内容仅在对应明确时拆行；未提供题号、考试地区，不宣称为逐题核实的真题数据库。
- `question-bank/exam-sources/`：22张原图，每条年度记录保留来源路径。共用同张图的模块不重复存放图片。
- 默认2021—2025；2020只含机械效率、电磁学局部数据，其余显示缺资料，不能视为未考。
- 热力图显示原表无疑点分值之和，或考查覆盖。疑点标注“待核”，部分明确分值标注“已知分值＋待核”。详情保留原表分数组，不按知识点重复分摊，多个题型共用总分时不强行拆分。
- 不统计独立题量、整卷总分/分值占比，不把认知层次等同难度。题型矩阵圆点仅表示涉及。
- 共享/重复疑点均不计入分值累计：2025热运动/热量/比热容三条6分，2022/2023内能分值组，2023机械能与机械效率重复条目，部分受力作图记录，2022欧姆定律包含关系。2021功和功率按图保留5、5，与Markdown单个5分冲突标为待核。压强2024计算、滑轮2023综合的分值保持缺失。
- 安全用电2023内容过泛、串并联2023具体规律不明，保留原分组并提示待核。
- 9组跨学科复习关注按知识点关联，保留Markdown原文和待核条目编号；不计入历年考频，不展示为预测结果。

## 交互

- 年份多选、近三年、全部完整年份，大类过滤、原表分值/考查覆盖。
- 模块/单元格点击后高亮，在同页下方展示年度柱图、题型矩阵、考法表；选中记录展示年份/题型/原分值/认知层次。
- 原图弹窗支持关闭与Escape；原图是考情汇总依据，尚未对应原试卷题号。
- 进入练习：清空旧题目筛选后，按该记录关联知识点的任一个与题型的任一个匹配；单一题型复用已有选择框，多题型用独立可取消标签。未限制练习年份，未以认知层次强制过滤。
- 可逐项取消知识点/题型标签，加入现有试题篮。返回考情恢复年份、模块、记录和页面滚动位置。
- 无私人题目时仍可看全部考情；选题结果诚实显示空结果。浏览、筛选、加入临时试题篮不改写题库、审核、使用记录与settings。
- 资料为网站随附静态数据，更新不需要重新导入私人题库；私人备份继续按现有机制运行。

## 验证

`npm run test:exam`（需Playwright Chromium或CHROME_EXECUTABLE）：数据ID/来源完整性、空题库、待核分值、年份/大类/指标、原图、单题型/多题型选题、取消标签、加入试题篮、返回、手机宽度、跨学科联动，以及操作前后IndexedDB三表不变。

回归：原有distribution浏览器流程、inline-dialog、merge-details、dashboard-page、filter-layout。桌面和390px手机截图检查；截图字体仅测试时注入，不添加到产品。
