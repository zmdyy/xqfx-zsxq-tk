# AI 短练习推荐规则

规则版本：`20261030-evidence-v2`。实现入口为 `ai-practice-rules.js`，由核心模块、页面和选题依据共同使用。

## 请求与检查

每次正式推荐都发送 system 规则、版本号、`teachingContract`、逐次成绩、作答状态、原题、知识星球关系和候选题。候选包含原始难度、完整题干、答案与本地任务分析。返回后校验候选 ID、有效证据、考试关系、计分范围、完整题范围、题量、基础起点和已发现的解析冲突；最多自动修正一次。DeepSeek、GLM 和自定义兼容接口共用业务规则。

成绩在模型输入阶段补充 `examRole`、`scoreScope`、`subpartScoresKnown` 和推断限制，不改动旧成绩数据或旧结果指纹。本次其他题不属于历史考试；整题失分不能定位具体错空。引用编号有效不代表错因或学科内容已经证实。

默认一至两道完整题，允许一道结束。计算基础补偿优先独立公式直代，不能将综合题中某个简单小问描述成整题简单。候选从全部匹配题中重新排序，优先低负担和基础题，不只截取旧排序前十二题。未识别到基础题时在 API 调用前说明缺题，不编题、不自动用综合题代替。概念和实验任务不强制公式题。

## 保守分析的边界

任务类型、直代可能性、负担和局部矛盾目前采用按内容缓存的本地启发式分析，明确标记为 `probable` 或 `limited`，没有调用付费 API 预标注全部题库。单位、公式依赖、隐含条件及图片语义仍可能有遗漏；“未识别到基础题”不等于数学证明题库不存在基础题。

解析检查能发现部分明确的状态定义错误，以及答案分段对同一量偏差方向的矛盾，不代表全部解析已验证。检查针对答案及解析，不能将选择题中的错误选项当作题库错误。发现明确冲突时排除候选，不擅自改写原始题库。

原题排除增加长文本及数值匹配；原题文字缺失时尝试从同科原卷 Markdown 恢复带空格的题号。图片仍会发送给支持视觉的模型。仅凭通用图题短句不会判定为同题；只有图片、缺少文字与来源信息的原题，不能保证自动识别全部变体。当前不自动拆取小问，以免遗漏公共条件、图像或对应答案。

## 复用与导出

规则更新不会自动使旧付费推荐失效，不会因打开页面、切换模型、查看依据或导出而调用 API。旧结果可继续使用；页面提供明确的当前学生更新入口，失败则恢复旧结果。待审核题仍可选，不恢复逐题人工审核关卡。

Word 与选题依据使用相同导出编号和固定快照；依据同时记录所选人数、各人状态、实际进入 Word 的匿名序号和题目版本。快照只保留最近一次，图片复用任务资产。之后发生修改，当前依据会明确标明与此前 Word 不匹配，需重新导出 Word 获得一致快照。

AI 练习导出采用保守版面预算，将题目页和解析页成对交替排列，继续附反馈表；删除仅作为重复说明的末尾“分析”段时保留具体解答。网页预览用于阅读，Word/WPS 因字体和公式排版可能产生分页差异；超大不可拆表格、复杂公式等仍需后续样本验证。普通题库组卷保持原有导出路径。

依据仅手动导出，不含密钥或模型内部思考全文。不得向公开仓库提交学生原始成绩、私有题库、上传附件和测试渲染文件。

## 验证

- `npm run test:ai-practice`：跨知识点基础起点、全候选扫描、证据范围、规则请求、输出校验、快照、复用、反馈表和原生 Word XML。
- `npm run test:ai-practice:browser`：真实浏览器中的规则请求与修正、滚动预览、结果复用、模型切换、脱敏依据和 Word 下载。
- `npm run test:score-groups`、`node tests/report-title-import.test.cjs`、`node tests/full-data-backup.test.mjs`：计分关系、导入和备份兼容。

测试不使用真实密钥或付费模型调用。模型对真实题目的教学判断继续通过不同知识点、题型与学生样本迭代，不能仅以格式校验通过认定推荐正确。

分析步骤只引用证据编号，程序在每条引用的 evidenceContext 中附上考试关系和计分范围。兼容旧模型多填的范围字段，记录差异而不触发付费重试；未知证据编号仍拒绝。更新失败恢复旧结果时保留 lastUpgradeAttempt，导出依据（包括旧 Word 快照）同时包含失败请求，明确区分成功结果与失败尝试。
